# 素材

[入口](./SKILL.md) · [工作流](./workflow.md) · [准备](./preparation.md) · [脚本](./script.md) · [音色](./tone.md) · [风格](./style.md) · [素材](./resources.md) · [音效](./sfx.md) · [质量门](./quality.md)

本文件规定画面素材怎么收集、怎么交到成片时间轴。图标、字体、插画、录屏工具和 B-roll 站点的名单与许可以 [Video.md](../Video.md) 第 6 节和第 7 节为准，这里不重列整张表。音效见 [sfx.md](./sfx.md)。配音见 [tone.md](./tone.md)。

核对日期：2026-11-10。

## 输入和输出

输入是制作脚本、脚本阶段已盘点的素材、已核对的 `production/narration.srt`，以及可用的工程、Skill 和用户素材来源。沿用脚本中的素材 ID，补齐下表字段。成片放置区间和录屏文件内部片段分别记录。SRT 提供对白锚点，成片时间见 [timeline.md](./timeline.md)。还没核对 SRT 时，可以先列路径和许可，成片位置待定。

输出是视频工程里的素材清单。每条至少有：

| 列 | 要求 |
|---|---|
| 素材 ID 与路径 | 保留脚本引用的 ID。路径相对视频工程。composition 实际加载的路径若不同，两处都写 |
| 种类 | 截图、录屏、出镜、图解、图标、字体、动效、生成图、代码绘制界面、素材库候选 |
| 成片区间与对白锚点 | 记录成片放置区间和相关的台词段 ID。无对白时标明用途，例如独立演示或片头 |
| 素材内片段 | 录屏和出镜成片要有。静图写「整幅」 |
| 来源 | Skill 或包名、版本或提交（可取得时）及原始条目；外部素材记录 URL 和日期，用户素材标「用户提供」 |
| 作者、许可、署名 | 未知就写「待确认」，并且不进画面 |
| 自带声音 | 保留、静音，或只留操作声。辅助录屏的解说默认静音 |
| 实际路径 | 降级后真正用的那一个来源，与 `production/paths.md` 一致 |

第三方许可要求署名时，把署名句子集中到一处。没有需要署名的素材时，不要为了凑片尾去写一份署名。

## 通用素材的选用顺序

适用于音效、配乐、图标、字体、插画、装饰性空镜、动画、特效、转场和模板组件。逐项按分镜意图判断：

1. 先用当前采用的 Skill、模板或工程自带的资源。检查当前版本实际有什么，适合本镜头、质量够、能进工程且许可清楚时，直接复用并登记来源。现成素材已满足需求时，可以继续制作。
2. 有缺口时，从已可用的官方包或合用的社区 Skill 补齐需要的部分。沿用当前画幅、风格和时间轴。仅引用所需资产或组件，安装依赖或下载的同意范围按工作流。
3. 用户自备素材和个人库是可选补充。适配度更好、有个人或品牌特色时可采用。用户明确指定使用的素材按其要求核对使用。
4. 仍有缺口时走下方资源表或 [sfx.md](./sfx.md) 的可用来源。仍缺合适的可选点缀时，省略或简化该处。

用本片上下文判断是否合适，包括声音的听感和混音、图像清晰度、字体字形和画幅、动画透明通道及渲染兼容。许可核到具体文件或组件，代码仓库的许可与素材条款分别记录。对已获准来源中符合上述条件的通用素材，可直接用于预览。实际使用的条目沿用试听与终检规则。

产品界面、真实操作、本人出镜和指定人声需要匹配本片的实际素材。可从用户文件、真实产品页面、录屏或官方包取得；Skill 自带的演示或装饰素材不能替代所需证据。需要代码绘制界面时，按下方「真实界面」的示意规则。

查找和重命名可以由 Agent 做。不要用无关画面填空。游戏或像素风的点缀，用仓库里的 [scenario-pixel-vfx](../VFX/scenario-pixel-vfx/SKILL.md)，按整数倍缩放。

## 降级顺序

把失败原因和实际使用的来源写入 `production/paths.md`。许可不清、需要署名而本片不能署名、或商用片上的 CC BY-NC，跳过该条并记下。付费或条款未核清的来源先问，不自动用。缺少必需的真实画面时标出缺口并向用户要文件。缺少可选画面时可省略或用能完成同一表达的图解。

| 需要 | 顺序 |
|---|---|
| 品牌标志 | Lobe Icons，没有再用 Simple Icons。要官方高清时先看 Brandfetch 的条款，条款不清就问 |
| UI 小图标 | Lucide，没有再用 Tabler。需要线宽或填充变体时用 Phosphor 或 Heroicons。搜索用 Iconify，子库许可仍按 Video.md |
| 动效点缀 | LottieFiles，逐条看授权。这一条许可不清就换下一条，不换来源类别去冒充 |
| 场景插画 | Neu Icons、Twemoji、unDraw，按 Video.md 是否需要署名。Storyset 一类常要署名，写进清单 |
| 字体 | 用户点名的文件。文件缺失就问。没点名时优先用本机已有且许可适用的 Noto CJK。需要下载时先取得同意 |
| 产品画面 | 用户的文件，然后是当时打得开的真实页面或 OBS 录屏。站点打不开就向用户要文件 |
| 空镜和封面 | 只作候选。来源限于 Video.md 第 7 节已经列出的镜头站，目前是 Pexels、Mixkit。各看各的许可，不标成 CC0。见下文「素材库候选」 |
| 结构图 | Anatomy。它失败时向用户要图，或在他同意后做一张标明「图解」的示意图 |
| 像素点缀 | 仓库内 scenario-pixel-vfx |

## 素材库候选

空镜、背景和封面可以检索 Video.md 第 7 节已经列出的镜头来源，目前是 [Pexels](https://www.pexels.com/) 和 [Mixkit](https://mixkit.co/)。再有别的，也只打开那一页已经写上的镜头来源。提出一份短名单，每条有路径或 URL、许可，以及成片区间或对应的台词段 ID。无对白区间标明用途。

候选不是已用素材。进画面之前，要么用户确认这一条，要么本轮已经在素材清单或 `production/paths.md` 写下接受规则，并且这一条符合规则。例如「非产品画面可以用许可清楚的 Pexels 空镜」。没有这样的规则，就逐条问。

素材库画面和生成图不代替产品截图、录屏或官方素材。产品界面缺了，仍记成缺口，或做成清单里标明的图解。许可不清的不进候选可用列。商用片上的 CC BY-NC 不进画面。付费素材站先问。

实际选用的来源写入 `production/paths.md`。

## 真实界面

产品介绍和技术讲解的演示段，默认是截图、录屏或官方素材。video-shotcraft 已安装且这段是产品界面时，优先跟随它的采集。video-talkcraft 已安装且这段要证据截图时，优先跟随它。都没有时，用上面的顺序和 Video.md 第 7 节的 OBS。缺文件就记缺口，向用户要，不画假界面。

代码绘制界面时，清单的种类写成「代码绘制界面」，备注写明用户已接受。观众会把它看成真实产品时，画面或旁白里说明这是示意。[Launch Video on X](https://www.remotion.dev/prompts/launch-video-on-x) 用代码画界面，本文件不把它当成默认。

OBS 是工具，不是 Skill。录屏里的解说默认不进成片。

## 命名

文件名使用小写英文、数字和连字符：`{种类}-{内容}-{来源简称}.{ext}`。种类用 `shot`、`screen`、`presenter`、`icon`、`font`、`mg`、`diagram`。不要用 `final`、`new`、`222`。

Remotion 要读取的文件放到工程的 `public/`，或官方 Skill 要求的位置。

## 透明通道和角色

角色动画按分镜需要选用，可复用合用 Skill 自带或用户提供的素材。带 Alpha 的视频要验证这条渲染链保留透明。Video.md 记录的示例是 HEVC（Alpha）。普通 H.264 MP4 不能当成透明素材。验证失败就改用该链支持的格式或 PNG 序列。抠像只对有权处理的素材做。

## 交到段落

- 用台词段 ID 和实际区间对上制作脚本。
- 录屏使用素材内片段，不把整段原始文件铺进一个短句。
- 形态 A 的出镜镜头用脚本里已经决定的形状、位置和运动。B-roll 盖住脸时，人声仍是那条主音轨。
- 形态 B、C 不把素材框成出镜表演。
- 图解放在它解释的段落，必要时跨句或留到停顿里供观众阅读。
- 清单没有的画面，先补清单再进工程。

## 失败时

| 现象 | 处理 |
|---|---|
| 站点打不开或需要登录 | 向用户要截图或录屏 |
| 只有低分辨率官方图 | 在清单写明尺寸。放大到模糊就换素材 |
| 许可冲突 | 从画面拿掉，换一条许可清楚的，或请用户决定 |
| 素材库画面被当成产品界面 | 拿掉。改记缺口，或改成标明的图解 |
| 透明素材在预览里变成黑底 | 标成未通过，换格式后再用 |
