# 单行字幕

适用于口播字幕。准备时按成片画幅和发布平台定可用区域，脚本起草时据此分节，转写后按真实发音切分，初剪和全片都检查实际画面。

## 字数和宽度

- 每条字幕只显示一行。中文或中英混排默认横屏、方形最多 **16 个全角等效字**，竖屏最多 **12 个**。汉字、全角符号和其他非 ASCII 字素计 1，ASCII 字母、数字、标点和内部空格计 0.5。计数包含实际展示的说话人标签。其他语言在准备时按目标语言和版式定字数上限。
- 字数是预检。还要等实际字体加载后，用 `measureText()` 或实际 DOM 尺寸按正式字号、字重、字距测量每条字幕。文本、描边和底板内边距都须装进安全区，竖屏还要避开平台操作按钮。多个交付画幅各自测量，必要时另存各自的显示用 SRT（例如 `production/narration-9x16.srt`）。派生版本仍使用音轨相对时间和原有台词段 ID 对应关系，见 [timeline.md](./timeline.md)。
- 字幕组件禁止自动换行。SRT 中没有内嵌换行。渲染前报告超宽条目并修正。保留全片统一字号，用语义分段或调整整套版式解决超宽，避免逐条缩字、截断或显示省略号。

## 断句、节奏与位置

1. 一条只放同一说话人的一个短语义单位。超限时优先在停顿、标点或分句处拆开，避免拆散专名、数字与单位、英文单词或代码标识。很长的命令可以由旁白简述并在画面完整展示。原音已经逐字读出的内容仍须保留。超宽的不可拆专名先在词组边界拆分，仍放不下时调整该画幅的整套版式或在确有必要时与用户确认替代写法。
2. 新条目的起止用真实发音或核对过的词级时间。只有句级 SRT 时回听找切点。自然停顿留空。合并过短条目须同时满足语义、宽度、同一说话人和时序；避免在长停顿上挂着旧字幕。参考节奏为约 7 全角等效字/秒，超过 9 或显示不足 0.8 秒时逐条回看。语速过密时，C 优先改写并重配，A/B 优先重新分段并回看。保留原录音的内容，无法缓解的高密度区间写进验收记录。
3. 字幕位置和基线在相邻镜头间保持稳定。遮挡人脸、操作区域、命令或平台控件时，优先调整构图，或把同一场景的一组字幕移到统一的安全位置。使用稳定的衬底或描边，浅色和复杂背景都要能读清。
4. 默认字幕整条稳定显示。词级强调只用已核对的词级时间，强调前后不要改字宽或引起跳动。切镜和转场时，仍在说的同一句可连续显示。

在 Studio 与导出文件检查最长条目、中英混排、快语速、亮底和切镜处。以成片上实际可见的一行为准。

参考 [Netflix 简体中文定时文本指南](https://partnerhelp.netflixstudios.com/hc/en-us/articles/215986007-Chinese-Simplified-Timed-Text-Style-Guide) 的字符数与阅读速度，以及 [Remotion 字体测量说明](https://www.remotion.dev/docs/layout-utils/debug)。这里的单行规则、竖屏字数和节奏阈值是本 Skill 的制作约定。
