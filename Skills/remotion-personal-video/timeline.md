# 音频、字幕和画面的时间

成品主音轨是时间基准。`production/narration.srt` 记录人声在音轨上的位置，零点是音轨的开头。保留停顿时在音轨里保留实际静音，SRT 在这段时间留空。成片加独立片头时，在 Remotion 中把主音轨和 SRT 一起向后放置，原 SRT 继续保留音轨相对时间。

## 音画同步与素材落点

1. 真人出镜时，剪顺后的出镜画面和同一次录制的原声使用相同的剪辑偏移；只有讲解音频时，以确认后的音轨为基准。SRT 从实际主音轨生成。画面、声音和字幕都映射到同一个 composition，它们各自可以有不同的起止。
2. 先照分镜执行明确约定。用 SRT 的文本和时间把分镜的语义节拍找到，再安排图片、录屏、动画、特效和音效。一个镜头可跨多条字幕，也可延续到停顿。只要实际发音和动作连续，切镜时可以保留正在显示的字幕。
3. 分镜留白时，AI 可以依据 SRT 上下文和实际素材补构图、辅助画面、动画或音效。遵守已确认的风格、素材许可和内容事实，保留可读时间。需要改变已确认的主要画面或关键演示时，先把改动交给用户看。
4. 用真实事件决定精确落点。跟词出现的强调用核对过的词级时间，点击高亮和点击声跟素材里的实际点击帧，结果动效跟结果出现帧。只有句级 SRT 时，需要精确卡词就回听对齐，无法定位时用句级强调或按实际画面事件安排。

例：旁白讲到「点击保存」时，按分镜提前展示录屏，让观众先看清按钮。点击声和高亮在按钮实际被点下的帧出现，成功提示留到读完再切。镜头可以覆盖两条字幕和中间停顿。

## 三种位置

| 位置 | 记录方式 |
|---|---|
| 主音轨与字幕 | 音轨相对毫秒。SRT 写对白及其起止 |
| 成片画面、音效和字幕 | composition 帧。镜头和音效用台词段 ID、音轨区间定位语义或用实际动作帧定位，也可在停顿、片头和片尾直接指定成片区间 |
| 录屏、出镜和其他视频 | 素材文件内部的入点、出点，与放到成片的区间分别记录 |

同一镜头可以跨几条字幕。镜头可在字幕结束后继续展示，音效落点以动作发生的帧为准。成片粗剪应覆盖全部区间，包括没字幕的片段。

## 台词锚点与字幕版本

逐镜稿、素材清单和音效表共用逐镜稿中的台词段 ID。台词段由说话内容和已核对的主音轨相对区间识别。SRT 序号仅用于查找当前文件的条目。比如 U03 对应音轨 10～13 秒，字幕从一条拆成两条后，两条都仍指向 U03。拆条或合并不重编台词段 ID。

`production/narration.srt` 保留已核对的主音轨相对时间，作为字幕来源。各交付画幅从它派生显示用字幕；按画幅拆条时保留相同音轨和台词段对应关系。只调整字幕分段时，复核该版本的字幕和已有序号备注即可。改动实际说话或剪辑时间时，重新核对对应台词段和下游区间。

## 映射到 Remotion

1. 使用 composition 的实际 FPS。约定片头、片尾为整数帧。把所有音轨相对边界统一换算为 `introFrames + Math.round(ms * fps / 1000)`。区间统一用含起点、不含终点的 `[start, end)`，`Sequence` 的 `from` 是起点，`durationInFrames` 是两者之差。共用边界只换算一次，避免相邻段分别取整造成重叠。取整后为零帧的字幕按 [captions.md](./captions.md) 调整分段，再核对。
2. composition 总帧数为 `introFrames + Math.ceil(audioDurationSeconds * fps) + outroFrames`，音频时长取自实际成品音轨。形态 A 的出镜与人声使用同一个剪辑起点。保留原声或单独铺主音轨二选一，B-roll 盖住人脸时人声连续。
3. 转场可以覆盖切点，或在两边镜头留足重叠。使用 `TransitionSeries.Transition` 时核算缩短的时长，保住既定的后续切点、字幕和音轨位置。
4. Studio 预览、样片和全片使用同一个 composition 和 props。CLI 的 `--frames` 含末帧。例：30 fps、60 帧片头，音轨上的 `[10s, 25s)` 对应成片的 `[360, 810)`，十五秒初剪用 `--frames=360-809`，共 450 帧。
5. 如果平台需要单独上传字幕，另外导出成片相对时间的 SRT，应用片头偏移并用实际导出文件校对。原始 `production/narration.srt` 继续用于制作。

检查 SRT 起止有效、按时间递增、无重叠、落在音轨长度以内。字幕的边界按统一方式换算后仍须有效。人声剪辑或语速改变时，先更新音轨和 SRT，再重算受影响的镜头和音效。若发生时长变化，从第一个改动点检查后续内容是否整体偏移。

参考 [Remotion 字幕绘制](https://www.remotion.dev/docs/captions/displaying)、[转场时长](https://www.remotion.dev/docs/transitions/transitionseries) 和 [渲染帧范围](https://www.remotion.dev/docs/cli/render)。
