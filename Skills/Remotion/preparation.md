# 准备

[入口](./SKILL.md) · [编排](./produce-prompt.md) · [工作流](./workflow.md) · [准备](./preparation.md) · [脚本](./script.md) · [音色](./tone.md) · [风格](./style.md) · [素材](./resources.md) · [音效](./sfx.md) · [质量门](./quality.md)

本文件是每次使用本 Skill 时的第一阶段。它只做开工前检查：外部工具、外部 Skill、外部素材和简报是否够把 [workflow.md](./workflow.md) 走完。检查通过之前，不写制作脚本，不调用音色，不收集成片素材，不渲染。

核对日期：2026-11-10。工具名单和许可以 [Video.md](../Video.md) 为准。这里不写 Remotion 组件，也不复制社区 Skill 的仓库。

## 立即停下

简报、素材或条件不够安全地往下做时，立刻停止，向用户列出缺的项，等他补上。不要用猜测填空。

典型的缺口：

- 形态不是下面的 A、B、C 之一，或者两可
- 片种不清，或产品介绍和口播讲解被同时要求
- 没有源文件路径（出镜成片、讲解音频，或只含讲解音频的视频）
- 形态 C 没有脚本或要点
- 形态 C 没有音色
- 没有画幅
- 没有语言
- 片种所需的社区 Skill 或官方 Remotion skills 不在当前会话里
- 要进画面的素材没有许可
- 产品介绍或技术讲解没有用户给出的产品名、地址或文件

不要编造产品、音色、画幅、镜头清单，或用户没给的媒体。缺的截图不要画成界面。缺的出镜不要用素材库里的人代替。缺了 shotcraft 或 talkcraft 时，不要自己写一套镜头步骤。

只读检查可以做：路径是否存在、技能列表里有没有对应 Skill、本机是否听得到 AudioSmith。安装、下载模型、删除、克隆、脚手架和渲染，先把命令给用户看，同意后再执行。

## 先确认形态

三种形态互斥。开工回复里写明是哪一种，并请用户确认。用户已经用明白的话指定过，就不要再问一遍，但要把判定写出来。

| 形态 | 含义 | SRT 从哪来 |
|---|---|---|
| A 真人出镜视频 | 有一个真人对着镜头的画面，成片里要安排这个镜头 | 与画面一致的那条人声。做法在 [tone.md](./tone.md) |
| B 真人讲解音频 | 有真人说过的声音，没有要布局的出镜表演。声音可以是音频文件，也可以在一条视频的音轨里 | 这条讲解的人声。做法在 [tone.md](./tone.md) |
| C 没有真人只有脚本 | 没有真人录音，也没有出镜表演。只有脚本或要点 | 确认稿和样音之后的成品合成。做法在 [tone.md](./tone.md) |

片种（产品介绍、口播讲解、技术讲解）不是形态。三种片种都可以是 A、B 或 C。产品介绍在画面阶段打开 video-shotcraft。口播讲解和技术讲解打开 video-talkcraft。见 [workflow.md](./workflow.md) 的「画面」。

判定：

- 用户给了出镜表演，要在成片里出现这个人：A。
- 用户写「只有真人讲解视频」：按 B。意思是有真人讲出来的话，声音可以在视频文件里，但不要把画面当成出镜表演去布局。若画面明显是人对着镜头讲，和这句话冲突，停下来问。
- 同时有出镜视频和另一条讲解音频：优先 A。SRT 只用和画面一致的那条人声。不能确定哪一条跟画面一致，停下来问。
- 既有稿又有真人录音：不是 C。录音对得上出镜表演就是 A，否则是 B。稿只用来校对听写。
- 只有话题、没有稿也没有录音：若用户明确要先起草脚本，形态先标为 C，稿留到 [script.md](./script.md) 写完并确认。他没有请你起草，就停下来问。
- 以上都无法归入一条：停下来问。

出镜镜头的形状、位置和运动不是在本文件里选定的。形态 A 到了 [script.md](./script.md) 再记这些决定；用户没选时仍然要问，不要默认圆形或画中画。

形态确认之后不要自动改成另一种。那是用户看得到的选择。

## 检查清单

每一行都要有结论：就绪、不适用，或未就绪。有一行「未就绪」且该形态或片种需要它，就停。不适用要写原因。

| 项 | 怎么核对 | 就绪 | 未就绪时 |
|---|---|---|---|
| 形态 | 用上一节归类，并得到用户确认 | 只写 A、B 或 C | 停下来问 |
| 片种 | 看用户要的是产品介绍、口播讲解还是技术讲解 | 只写一种 | 两可或没说：停下来问。不默认打开两个社区 Skill |
| 语言 | 看简报里的口播语言 | 写明语言 | 停下来问 |
| 画幅 | 看简报里的宽高或平台画幅 | 有用户确认的宽高 | 停下来问。可以把 1920×1080 当作问题里的常见例子，不能擅自套用 |
| 片种和事实 | 产品介绍、技术讲解要有用户给的产品名、地址或文件 | 事实能指回用户或该地址 | 停下来问。不编产品 |
| 形态 A 的成片 | 打开用户给的路径，确认是视频且他认定这就是出镜素材 | 路径可读 | 停下来要路径 |
| 形态 B 的声音 | 打开音频，或打开视频并确认有音轨 | 文件可读且有人声来源 | 停下来要文件。不先合成一条代替 |
| 形态 C 的稿 | 看是否已有脚本或要点；或用户明确要求起草 | 有文本，或已约定由脚本阶段起草后确认 | 没有文本、也没要求起草：停下来问 |
| 形态 C 的音色 | 看是否点名了 AudioSmith 音色、给出了要听样音的描述，或给出了已授权的克隆参考 | 有上述之一 | 停下来问。不替他选一条预设声音，也不自动改去 Edge TTS |
| 识别能力（A、B） | 按 [tone.md](./tone.md) 的识别降级：本机叫得到 AudioSmith 的 `transcribe`，或叫得到 Video.md 已记录的 whisper.cpp | 至少一条能读这个文件 | 两条都没有：停下来问。不编造起止，不用飞书妙记或剪映，除非用户随后同意 |
| AudioSmith（仅 C，或 A/B 要用它识别） | 仅当会话就在主人的 Mac 上时访问 `GET http://127.0.0.1:3901/health`。端口以应用为准 | 有响应。C 若用户已改选并同意 Edge TTS，这一行改为不适用 | 远程会话不要连接 `127.0.0.1`。说明够不到，问他换到那台 Mac，或是否同意 Edge TTS。不自动换音色 |
| 官方 Remotion skills | 在当前会话的技能列表或用户指出的安装位置查找 remotion-dev/skills。要能打开创建、markup、Studio、渲染和字幕这几项；安装后的目录名以技能列表为准 | 能找到这一组 | 给出 `npx skills add remotion-dev/skills`，同意前不安装 |
| 片种对应的社区 Skill | 产品介绍查找名为 `video-shotcraft` 的 Skill。口播讲解和技术讲解查找 `video-talkcraft`。确认能打开它的 SKILL.md | 找得到 | 给出下面的安装命令，同意前不安装。未安装时停，不改用自己写的镜头步骤 |
| 渲染工具链 | 看用户指出的工程里是否已有 Remotion | 工程能按官方 Skill 预览，或用户已同意新建 | 同意前不跑脚手架。首次同意后，先渲染几秒深色背景加一行字幕的最小例子，这不是正片，也不配音 |
| 字体 | 用户点名的字体文件是否存在、许可是否已知 | 文件在，许可已记 | 停下来要文件或许可。未点名时，询问是否使用 Video.md 第 7 节的 Noto CJK，同意前不下载 |
| 截图、录屏和其他画面 | 对上简报里的演示。路径能打开，或官方页面当时打得开 | 演示所需的文件或地址已列出 | 产品或操作演示缺素材：停下来要 |
| 许可 | 每条已给出的第三方文件有许可或署名；用户自己的出镜和录音记为「用户提供」 | 没有空的许可栏 | 空着的不进入后面的画面。商用时 CC BY-NC 视为未就绪 |
| 风格仓库 | 不在开工时逐个安装 | 记为不适用，留到 [style.md](./style.md) | 用户已经点名某一个时，只核对那一个能否打开 |
| 帧率 | 看工程或简报 | 用户指定了，或尚未指定 | 未指定不挡住准备。新建工程时用 30 fps。用户另有帧率就改 |

社区 Skill 的安装命令，同意后才执行：

```bash
npx skills add Vincentwei1021/video-shotcraft
npx skills add Vincentwei1021/video-talkcraft
```

安装依赖若因网络停下，再问是否按 Smartpigai 文章里的做法使用国内镜像。镜像不是默认步骤。

风格仓库、音效库和图标库不在这一步全部装齐。后面的阶段按各自的降级顺序处理缺失，规则在 [workflow.md](./workflow.md) 的「路径失败时」。

## 准备阶段的产出

在回复里留下这张清单的结论。视频工程已经存在时，把同一份结论写到 `production/readiness.md`，不要写进 SkillsPocket。

通过的标准：该形态和片种需要的每一行都是「就绪」或「不适用」。然后才按 [workflow.md](./workflow.md) 进入下一段。形态 C 通过准备，仍然不表示可以合成全长。
