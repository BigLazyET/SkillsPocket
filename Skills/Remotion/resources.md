# 素材

[入口](./SKILL.md) · [编排](./produce-prompt.md) · [工作流](./workflow.md) · [准备](./preparation.md) · [脚本](./script.md) · [音色](./tone.md) · [素材](./resources.md) · [音效](./sfx.md) · [质量门](./quality.md)

本文件规定画面素材怎么收集、命名、核对许可，以及怎么交到一个段落。音效不在这里，见 [sfx.md](./sfx.md)。配音文件的生成见 [tone.md](./tone.md)。

核对日期：2026-11-10。选型表以 [Video.md](../Video.md) 为准，这里不复制一整份图标和风格目录。

## 输入和输出

输入是确认中的制作脚本、已核对的 `production/speech-timeline.srt`，以及用户给出的文件夹或网址。素材的入点、出点写的是这条时间轴上的时间，不另估一套。没有时间轴时，只列路径和许可，不写进成片的秒数。

输出是视频工程里的素材清单。每条至少有：

| 列 | 要求 |
|---|---|
| 路径 | 相对视频工程。composition 实际加载的路径若不同，两处都写 |
| 种类 | 截图、录屏、出镜、图解、图标、字体、动效、生成图、代码绘制界面 |
| 段落 | 对应制作脚本的编号。一段可以有多条，一条不要拿去填无关段落 |
| 入点–出点 | 录屏和出镜成片要有。静图写「整幅」 |
| 来源 | URL 和抓取日期，或「用户提供」 |
| 作者、许可、署名 | 未知就写「待确认」，并且不进画面 |
| 自带声音 | 保留、静音，或只留操作声。辅助录屏的解说默认静音 |
| 备注 | 分辨率、是否循环、透明通道格式、角色是否要保持同一比例 |

第三方许可要求署名时，另把署名句子集中到一处，供片尾或描述使用。没有需要署名的素材时，不要为了凑片尾去写一份署名。

## 收集顺序

1. 用户已经放进工程或指明路径的文件。
2. 产品自己的界面：打开简报里的真实站点、应用或仓库，截图或用 OBS 录屏。记录 URL 和日期。打不开就向用户要文件，不要凭记忆画一个。
3. 官方品牌包、官方截图、用户自己的角色和透明动画。
4. Video.md 里已经选过的图标和插画。缺图再往下。
5. 图解。结构说明可以用代码或 SVG 做，种类标「图解」。技术结构图可评估 Video.md 提到的 Anatomy；它产出的是图，不是一条已经对好时间的视频。
6. 用户同意的生成图。标明生成工具，不要把它写成产品照片。
7. 代码绘制的产品界面。只在上面几步都没有，并且用户明确接受时使用。

查找和重命名可以由 Agent 做。画面是否真的对上讲解，要在清单里写清，并在短样片里让人看见。不要用无关画面填空段落。

游戏或像素风的点缀，用仓库里的 [scenario-pixel-vfx](../VFX/scenario-pixel-vfx/SKILL.md)。进视频时按整数倍缩放，不把像素滤成模糊。

## 真实界面

产品介绍和技术讲解的演示段，默认是截图、录屏或官方素材。

代码绘制界面时：

- 清单的种类写成「代码绘制界面」，备注写明用户已接受。
- 观众会把它看成真实产品时，画面或旁白里说明这是示意，不只藏在清单里。
- 不要用它冒充某一张当时没截到的设置页。

[Launch Video on X](https://www.remotion.dev/prompts/launch-video-on-x) 的提示词要求用代码画终端、主页和聊天界面。那是该示例的做法。本文件不把它当成产品片的默认。

录屏用 OBS 一类工具即可。OBS 是工具，不是 Skill。录屏里的解说默认不进成片；操作声要留的话，在清单里单独写，并在 [sfx.md](./sfx.md) 里跟主旁白一起听音量。

## 命名

文件名使用小写英文、数字和连字符，扩展名保持真实格式：

`{种类}-{内容}-{来源简称}.{ext}`

种类用 `shot`（录屏）、`screen`（截图）、`presenter`（出镜）、`icon`、`font`、`mg`（动态图形或 Lottie）、`diagram`。例如 `screen-settings-official.png`、`shot-export-obs.mp4`。

不要用 `final`、`new`、`222` 当文件名。同一角色的多段动作，文件名里写动作和朝向，清单里写时长、是否循环、透明格式。

Remotion 要读取的文件放到工程的 `public/`，或官方 Skill 要求的位置。清单保留这个路径。

## 许可

仓库的 MIT 许可不覆盖这些素材。每条第三方素材自己的许可才算数。

- 图标的默认去向以 Video.md 第 6 节为准：品牌 logo 先 Lobe Icons，没有再用 Simple Icons，要官方高清时看 Brandfetch 的条款。UI 小图标先 Lucide，缺了用 Tabler。动效点缀用 LottieFiles，逐条看授权。场景插画里 Storyset 一类常要署名。
- 品牌商标和素材仓库的开源许可不是一回事。能下载到 SVG，不等于可以在商业广告里任意使用该商标。
- Pexels、Mixkit 按它们各自的许可使用，不标成 CC0。
- CC0、CC BY、CC BY-NC 分开写。CC BY-NC 不用于商用片子。
- 字体随文件记下许可。用户没指定时，先按 [preparation.md](./preparation.md) 询问是否使用 [Noto CJK](https://github.com/notofonts/noto-cjk)（SIL Open Font License），同意后才用。渲染前确认字体已经加载，做法用官方 Remotion Skill，不在这里写加载代码。

许可是「待确认」的，不进入 composition。

## 透明通道和角色

用户已有的角色小动画优先复用，不要每支片子重新画一个。

带 Alpha 的视频要验证这条渲染链真的保留透明。Video.md 记录的示例是 HEVC（Alpha）。普通 H.264 MP4 不能当成透明素材。验证失败就改用该链支持的格式或 PNG 序列，并在清单里写结果。

抠像只对有权处理的素材做。绿边和主体自身的绿色要分开看，避免把角色抠缺。

## 交到段落

画面阶段只读清单里已经能用的条目：

- 用「段落」列对上制作脚本，不用文件名猜测。每段的出现时间引用主语音时间轴的序号或起止。
- 录屏使用入点–出点，不把整段原始文件铺进一个短句。
- 形态 A 的出镜镜头用脚本里已经决定的形状、位置和运动。B-roll 盖住脸时，人声仍是那条时间轴。
- 形态 B、C 不把素材框成出镜表演。
- 图解放在它解释的那一句的时间里，不抢演示段的位置。
- 清单没有的画面，先补清单再进工程。不要在代码里临时发明一张未登记的产品图。缺文件就停下来问。

## 失败时

| 现象 | 处理 |
|---|---|
| 站点打不开或需要登录 | 向用户要截图或录屏。不画一个假的登录后界面 |
| 只有低分辨率官方图 | 在清单写明尺寸。放大到模糊就换素材，不在成片里硬拉 |
| 许可冲突 | 从画面拿掉，换一条许可清楚的，或请用户决定 |
| 透明素材在预览里变成黑底 | 标成未通过，换格式后再用。不把黑底当风格 |
