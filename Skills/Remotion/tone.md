# 音色

本文件只规定视频流程里何时转写、何时出样音、失败后换哪一条，以及何时必须征得同意。工具参数、版本和模型体积不写在这里：以 AudioSmith 当时的 README、`docs/local-api.md`，以及应用生成的 Skill 为准。本机版本不同就跟本机。

核对日期：2026-11-10。语音名单在 [Video.md](../Video.md) 第 3 节。SRT 的含义以该页「SRT 是配音与画面的时间依据」为准。Video.md 把 VoiceStudio 与 AudioSmith 都列为本地工作台，并写明未逐项实测。主人的 Mac 上叫得到 AudioSmith 时，形态 C 走它。这不改写清单的排名。

## 按已确认的形态

形态还没确认时，回到 [preparation.md](./preparation.md)。

| 形态 | 主音轨 | SRT | 不做什么 |
|---|---|---|---|
| A 真人出镜视频 | 与画面一致的那条人声 | 识别该成片的音轨 | 不另做 TTS，不为对口型分析嘴型，不叠第二条讲解 |
| B 真人讲解音频 | 用户给出的讲解 | 识别音频，或识别那条视频的音轨 | 不把画面布局成出镜表演，不用 TTS 替换人声 |
| C 没有真人只有脚本 | 指定音色的 TTS | 合成结果再对齐 | 稿未确认、样音未通过时不做全长 |

A、B 的文件若还不是要用的那一条，停下来问。不自行剪口误。社区 Skill 若要先剪口水词，先把报告给用户看，同意之后才改文件。

主音轨若从视频里抽出来单独铺，视频自带的音轨必须静音，并且起点一致。保留视频原声、不再另铺一份，也可以。两种只选一种。降噪、均衡、压缩只在用户要求时做。

## SRT

三种形态都交出 `production/narration.srt`。来源说明写在 `production/narration-srt.md`：形态、源文件、实际用的识别或合成路径。字幕、画面和音效引用这份 SRT 的序号和起止。

合格的标准：覆盖从第一句到最后一句；每条有序号、起止和实际听到或合成出来的词；没说出口的句子不在里面；起止来自成品音轨，不来自字数。稿子只改人名、术语、英文品牌和同音字。句级 SRT 不是逐字高亮。词级时间必须落在所属条目的起止之内。

对照音轨听开头、中段、结尾和最长的停顿。断句和大约 8～18 个汉字的示例宽度见 Video.md。绘制用官方 `remotion-captions`。为留画面而加的停顿要写回音轨和 SRT。

### 识别的降级顺序

用于 A、B，以及核对 C 的合成草稿。失败和实际路径写入 `production/paths.md`。

失败指：工具不在、命令失败、结果是空的，或起止盖不住这段人声。专名听错用稿子改，不换工具。

1. 会话在主人的 Mac 上且 AudioSmith 有响应：用它的转写。文件必须真的交进去。
2. 工具读不了容器：用 Video.md 第 7 节的 FFmpeg 抽出音轨，再送回同一步。参数以本机文档为准，这里不写未核对过的命令。
3. 上一步没有或报错：whisper.cpp 运行 Whisper `large-v3-turbo`。
4. 用户本轮已经指定另一个当前会话能调用的本地模型：用他指定的。
5. 飞书妙记、剪映不自动使用。本地路径都失败后问；他同意才用。
6. 都失败：停下来问。不按稿子填写起止，也不用 TTS 冒充 A、B 的声音。

没有成品音轨时，不写 `narration.srt`。AudioSmith 或 Edge TTS 附带的字幕只是草稿，仍走上面的核对。

## 形态 C 的配音

换音色会让观众听到的声音变掉。除了第 1 步，都要先问。问过的那一条失败后，再问，不自行改去下一条。A、B 不走这里。

1. 主人的 Mac 上 AudioSmith 有响应：先样音，通过后才合成全长。
2. 人在那台 Mac 上但没有响应：请用户打开应用。仍然没有，问他换机器或是否同意 Edge TTS。
3. 会话不在那台 Mac 上：不连接 `127.0.0.1`，也不把连不上说成应用损坏。问换机器或 Edge TTS。
4. 用户点名 Video.md 第 3 节里的 VoiceStudio、GPT-SoVITS、VoxCPM2 或 IndexTTS：用他点名的那一个。不逐个自动试。
5. 用户同意之后才用 Edge TTS。它失败就再问。

样音用这支片子里的术语、一处中英混读、一个长句。听读音、漏字、语气、语速和停顿。通过之后才合成全长，导出 WAV 或 M4A，再写成 SRT。读错专名时改正文再出样音，不换引擎。

送进 TTS 的只有要念的正文。屏幕文字、素材备注和段落标题先去掉。不假定工具会忽略【旁白】之类的自定义标记。AudioSmith 自己的控制标记可以留着，写法以应用当时的文档为准；SRT 里写听众听到的词，不写标记。

音色怎么描述、候选怎么保存、克隆要哪一句同意，以应用生成的 Skill 为准。调用克隆、下载模型和删除之前，先得到用户同意；克隆只用于用户本人或他已授权的录音。商用片不要默认 OmniVoice，Video.md 记下它是 CC BY-NC。响度档位若应用提供，选一档写进记录，判断见 [quality.md](./quality.md)。

### 何时叫得到 AudioSmith

只在当前会话就在主人的那台 Mac 上、应用已打开时调用。默认基址是 `http://127.0.0.1:3901`，端口以应用设置为准。已经确定是这台 Mac 时，才看它是否在听。远程会话不要发起连接。

接入方式、MCP 或 API 的路径、每个工具的参数，读应用里生成的配置和 Skill，或当时的 `docs/local-api.md`。不要在本文件抄一份会过期的参数，也不要猜一份请求体盖掉本机配置。生成的配置可能含密钥，留在本机，不写入视频工程和本仓库。

## Edge TTS

只用于形态 C，并且只在用户同意之后。它不是音色设计，也不是克隆。指 [rany2/edge-tts](https://github.com/rany2/edge-tts)。

- 用 `--list-voices` 让用户选 ShortName。不替全片默选一个。
- 需要网络。不能按描述设计新音色，也不能克隆。
- 语速和音量用 `--rate`、`--volume`。负值写成 `--rate=-10%`。
- 自定义 SSML 已从该工具移除。调用前看本机 `edge-tts --help`，不要假设 `--pitch` 仍然有效。
- `--write-media` 出音频，`--write-subtitles` 出草稿。草稿仍要核对。
- 安装先问用户。商用许可本仓库没有核完；商用片要告诉用户，不要宣称已经授予商用权。

Smartpigai 文章的搭建示例写的是 Edge TTS。主人这台 Mac 上 AudioSmith 可用时，不用那一条做默认。

## 失败时

| 现象 | 处理 |
|---|---|
| 形态还没确认 | 回到 [preparation.md](./preparation.md) |
| 不在主人的 Mac 上 | 不调用 127.0.0.1，按上面的顺序问。不自动换音色 |
| A、B 的本地识别都失败 | 停下问。不编起止 |
| 要下载模型、克隆或删除 | 先给用户看，同意再做 |
| 样音读错专名 | 改正文，重新出样音 |
| 人声改了某一句 | 重做受影响的音频和 SRT。不把新旧两段叠在一起 |
