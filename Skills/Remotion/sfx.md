# 音效

[入口](./SKILL.md) · [编排](./produce-prompt.md) · [工作流](./workflow.md) · [脚本](./script.md) · [音色](./tone.md) · [素材](./resources.md) · [质量门](./quality.md)

本文件规定音效和配乐怎么选、怎么对时间、怎么限制音量。它不包含 Remotion 的 `<Audio>` 写法；进工程的方式用官方 Remotion Skill。

核对日期：2026-11-10。来源表和「不默认使用按月配额的文生音效」以 [Video.md](../Video.md) 第 2 节为准。

## 输入和输出

输入是确认过的 SRT、短样片确定的画面，以及已有的个人音效库索引。没有索引时，从本片开始建，格式见下。

输出是一份音效表，每条有：路径、听感、对应段落或 SRT 时间、用途、时长、峰值大概落在哪里、来源、作者、许可、署名句子。配乐单独成行，不和短音效混在同一条里。

人听过之后，在该条写下「已听」以及是否使用。只有文件、没有这一句，不算完成。

## 选用顺序

1. 个人库里已经听过、许可仍适用的条目。
2. [@remotion/sfx](https://www.remotion.dev/docs/sfx/)。该页在 2026-11-10 写的加入方式是 `npx remotion add @remotion/sfx`。执行前把命令给用户看。上游写明峰值归一到约 −3 dB，可以不署名，署名信息在单条详情页。适合 whoosh、点击一类起步短音。
3. [earshot](https://github.com/Leonxlnx/earshot)，用于电子短音。命令形状是 `earshot sfx render <id> -o <file.wav>`。ID 用它自己的列表，不在本文件抄目录。Video.md 核对过的例子是 `whoosh_fast/crisp`。产物 WAV 再交回工程。
4. Kenney（CC0）和 Freesound 上选择的 CC0，用来补真实质感。Freesound 逐条看许可：CC BY 要署名，CC BY-NC 不用于商用。
5. Mixkit、Pixabay，按它们各自的许可，并保存条目页面。两者都不是统一的 CC0。
6. 免费来源里没有合适的，才询问是否使用 Envato 这类付费库。

不把 ElevenLabs、按月配额的文生音效放进默认路径。Video.md 写明这是当前选型，不是那些产品没有免费层的结论。

宣传片若要评估 video-shotcraft 自带的音频，先按 Video.md 核对具体文件的许可，再决定是否拷进 `public/sfx`。

## 什么时候出声

音效标记动作，不标记句子。

| 画面 | 可以用 | 限制 |
|---|---|---|
| 卡片或章节切换 | 一声 whoosh | 轻重和时长跟运动一致。不是每次切都要 |
| 元素出现、完成 | 短的 pop 或 ding | 不要每条字幕都响 |
| 操作演示里的点击、打字 | click，或一段打字循环 | 循环只覆盖真的在打字的时间 |
| 翻页、拍照等有实义的动作 | 与动作同名的一声 | 没有这个动作就不出这个声 |
| 章节抬起 | 短 riser | 一支片子里少用，音量低于旁白 |

旁白正在说关键词时，不叠一声会盖住字的音效。尾音不要拖进下一句的关键词。

配乐和音效分轨。旁白出现时把配乐降低，句间可以稍抬。不要为了压配乐去抬旁白直到爆音。

辅助录屏自带的解说保持静音。清单里写明要留的操作声，才作为音效轨的一条，并跟主旁白一起听。

## 音量和时间

- 主音轨是前景。[quality.md](./quality.md) 管整片响度。音效即使来自峰值约 −3 dB 的素材，叠上旁白时仍要再降。
- 切点用 SRT 和画面动作的时间，不用「大概在这一段」。
- 改了主音轨或 SRT 之后，重对受影响的切点。不要把旧时间留在新旁白上。
- 同一声在全片反复使用时，间隔开，避免听成提示音故障。

Agent 没有真正播放音频时，只能按文件名、标签和说明列出少量候选，并写明「尚未试听」。候选控制在能一次听完的数量，不要一次丢来几十条。

## 索引

个人库索引保持为表，不把音频文件提交进 SkillsPocket。建议的列就是上面的输出列，外加「适用动作」。

命名沿用 Video.md 的例子：`whoosh-soft.wav`、`pop-bubble.wav`、`click-ui.wav`、`typing-loop.wav`、`paper-turn.wav`、`riser-short.wav`。名字描述听感，不写 `sfx1`。

从别人的压缩包里拿到的声音，不因为「是剪辑师分享的」就当成许可可以转移。追到来源页再入库。

## 失败时

| 现象 | 处理 |
|---|---|
| 只有检索结果 | 停在候选。请用户听，或在本机播放后写下结论 |
| 音效盖过旁白 | 降音效或换更短的一条。不改旁白稿来躲开音效 |
| 许可是 NC 或不明 | 商用片拿掉。非商用也要在清单写明，不明的不进成片 |
| 代码合成的短音听感不对 | 换成品短音。Video.md 记录过一次合成听感不佳的实践，这不表示 earshot 不能用于合适的电子短音 |
